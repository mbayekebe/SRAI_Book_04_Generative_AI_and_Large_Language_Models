# PU-B04-C01: Generative AI and LLM Foundations

Book 4 opens with the mechanisms and evidence boundaries of generative AI. The lesson connects tokenization, embeddings, autoregressive generation, attention and decoding with retrieval, evaluation, security and accountable institutional use.

## Learning outcomes

Learners will be able to:

- distinguish generative and discriminative learning;
- explain tokens, embeddings, context windows and next-token prediction;
- interpret attention without treating it as factual provenance;
- compare decoding policies and document inference settings;
- evaluate groundedness, correctness, safety and decision fitness;
- design an evidence chain for consequential generated output; and
- locate Lesson 1 within the Book 4 pathway toward building a small GPT-style model.

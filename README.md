# SRAI Book 4: Generative AI and Large Language Models

This repository is the umbrella publication repository for Book 4 of the Statistical Research and AI Institute learning ecosystem.

Book 4 develops a cumulative pathway from language-model foundations to production architecture, responsible institutional use and a compact educational GPT-style capstone.

## Book 4 learning destination

Across the complete pathway, ambitious learners will build and explain a small GPT-style model using tokenization, embeddings, causal attention, decoder blocks, training loss, generation and evaluation. The capstone is educational and computationally modest. It does not claim frontier-model scale or capability.

## Repository organization

Each lesson is maintained as a controlled production unit under `production-units/`. A production unit can contain the lesson, executable notebook, assessment materials, executive brief, presentation, video evidence, website payload and release controls.

## Integrity

Each released production unit includes a `SHA256SUMS` manifest and validation evidence. Use these files to verify downloaded assets before use.
